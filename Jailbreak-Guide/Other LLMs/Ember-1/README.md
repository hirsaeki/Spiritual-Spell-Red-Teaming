# Ember-1 (Fireworks Research)

Guide: **Ember-1** — a specialized reduced-thinking variant of **Kimi K3**, built by Fireworks Research (San Francisco).

*Last updated: September 2026*

## Thoughts

Ember-1 is Kimi K3 tuned to think less — roughly 40% fewer thinking tokens while holding output quality. I used it via OpenRouter on Max thinking, and it's just as easy to jailbreak and writes just as good as Kimi K3.

If you like K3 but want the reasoning cheaper and faster, this is it.
